Инструкция

  • Используйте кнопку "Переключить тему" чтобы переключаться между светлой и тёмной темой
  • Во вкладке "Цвета" вы можете изменить любой цвет с помощью color picker (только для текущей темы)
  • Во вкладке "Редактор CSS" вы можете редактировать CSS-код напрямую (только для текущей темы)
  • Когда найдёте подходящие цвета, скопируйте их из редактора CSS и обновите файл src/app/globals.css
